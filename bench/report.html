Scenario 2 — retry loop cut off

Priced from a real 91-token failed-attempt transcript. Assumes a subagent would blindly retry 6 times without the guard (override with --baseline-retries) — the sticky guard-loop.sh lets the first 2 attempts through, then denies every one after.

baseline6 × ~91 tok = ~548 tok
with plugin2 × ~91 + 4 × ~40 tok = ~342 tok

Each large block ≈ one real failed attempt (~91 tok). Each small block ≈ one sticky deny message (~40 tok) — the plugin still pays for the attempts up to the threshold; only the pointless retries after it get cheap.

Methodology & caveats

  • Token counts use ~4 bytes/token — the same approximation hooks/scripts/lib.sh uses at runtime, not a real tokenizer's exact count.
  • Scenario 2's baseline retry count (6) is a stated assumption, overridable with --baseline-retries — not a measurement.
  • These numbers describe this fixture set, not a general claim about all sessions.
  • For an exact number instead of an estimate, diff real session transcripts — see bench/README.md and bench/extract_usage.py.
